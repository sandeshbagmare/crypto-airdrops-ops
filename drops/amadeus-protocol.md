## Steps

1. Open the AMA Hub Tasks page and connect an EVM wallet.
2. Create an Amadeus wallet and link it. It comes as a browser extension and as apps for iOS and Android. The Tasks page says: "Every quest needs both wallets linked".
3. Check in daily and clear the repeatable quests.
4. Build an agent, give it a skill and run it, then work toward First Chair.
5. Claim your points each week, starting on Monday.
